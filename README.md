# 化玄个人网站

网站：https://evoxuan.com/  
仓库：https://github.com/evoxuan/evoxuan.github.io

首页、文章搜索与分类、阅读目录、数据故事、项目与关于页均由 Markdown 和配置生成。网页由 GitHub Pages 发布。访问人数统计依照本人最新要求暂不启用。

## 发布文章

1. 在 GitHub 仓库 `posts` 中新建 `YYYY-MM-DD-英文短名称.md`。
2. 按下面格式填写元信息和正文。
3. 提交到 `main`，等待仓库 Actions 绿色成功。无需逐篇修改布局。

```markdown
---
title: 文章标题
summary: 一两句介绍，用于列表和分享描述。
category: 写作
tags: [写作, 修改]
featured: false
---

文章正文。

## 一个章节

支持引用、列表、图片、表格和代码块。
```

日期默认取文件名。文件名决定稳定网址，发布后请保留。`featured: true` 表示首页精选，建议保持三篇。`draft: true` 隐藏网页中的文章，但公开仓库里的源文件仍可见，私人稿件不要上传。`initial: true` 标注 AI 辅助生成的初始稿；本人确认并改成正式文章后可删除这个字段。发生实质修改时才加入 `updated: YYYY-MM-DD`。`related: [另一篇文章的英文短名称]` 手动指定相关内容。

搜索匹配标题、摘要和标签，分类来自已有文章。元信息每项一行，不支持 YAML 多行字段。正文与标题应保持准确，不写未经确认的个人事实。

## 修改介绍、项目和社交链接

- `site.json`：网站名、简介、网址、真实社交链接、统计服务地址和最近在做的更新日期。
- `about.md`：关于页面内容。
- `projects.json`：项目名称、状态、说明、访问地址和详情正文。状态使用“可用”“实验中”“暂停”，链接必须有效。

目前三篇文章为经授权生成的初始稿，项目展示这个实际网站。没有真实链接的抖音、小红书、知乎暂不显示。

数据故事“阅读时间，是怎么算出来的？”每次构建测量当前文章的实际文字，提供图表、表格和可下载数据。400 字/分钟是编辑参数，不是普遍阅读速度结论。后续成绩故事需提供本人确认的数据与口径，不能用示例分数替代。

## 公开访问统计

当前 `statsEnabled: false`，网页不展示或请求统计。服务端已搭建，尚未通过当前网络的公开读取验证；恢复这项工作后，先验证服务可达与跨站访问，再设置 `statsEnabled: true`。以下是预留实现的口径。

服务地址由 `site.json.statsEndpoint` 指定，`GET /api/stats` 无需登录，仅返回汇总数字及统计日期。浏览器向 `POST /api/visit` 提交每天轮换的匿名随机标识；服务端保存按日哈希，用于去重，不保存 IP、浏览器信息或访问明细。标识短期清理，每日汇总长期保留。

按北京时间切日，同一浏览器当天重复访问尽量只计一次，跨日再次计入累计人次。不同设备、清除存储或屏蔽脚本会影响估算；匿名接口不能保证消除所有恶意流量。已知机器人、自动化浏览器、开发和预览写入被排除。浏览器存储不可用时跳过计数。

每个内容页都有公开数字和可展开的统计口径。构建时读取汇总快照；页面打开后异步刷新。异常时显示最近成功数据并注明时间，没有数据则显示“统计暂不可用”。浏览器缓存只用于故障展示，不作为统计来源。私密盐值配置在服务端，网页没有私密密钥。服务端源码位于本次交付的 `statistics-service`，维护说明见其中 `README.statistics.md`。

## 本地预览

需要 Node.js。执行 `node build.mjs` 生成 `_site`，再执行 `node preview.mjs`，打开终端显示的本地地址。网页使用随仓库保存的 Markdown 解析器，无需安装依赖。提交源码后 GitHub Actions 自动构建与部署。

每页提供独立标题、描述、规范地址和文字分享预览。平台是否展示预览、何时更新缓存由平台决定。
